🔎 作品URLの正規化チェック

新works正本DBを読み取り、通常・R18、検索除外・通常登録を問わず、なろう作品の旧形式URLを探します。url と siteData.sourceUrl の両方を検査します。最初の検査ではデータを書き換えません。

安全のための手順

① 全作品を読み取り検査 → ② 対象一覧とバックアップJSONを保存 → ③ ともたが確認 → ④ 修正ボタンで url と siteData.sourceUrl の旧形式URLだけを正規URLに置き換えます。

作品タイトル・作者・しおり・棚・その他の項目には触れません。URL以外のデータは変更しません。

検査待ちです。
