このページについて

GitHub mainのファイル配置・役割・依存関係を管理する資料です。現行ツリーと過去の構成記録を分けて扱います。最新のファイル一覧・変更履歴はMarkdown正本を参照してください。

リポジトリ構成表（Markdown正本）を開く

構成管理の基本方針

  • GitHub mainの実在ファイルを基準にする。
  • ShortcutやWorkflowから呼ばれる入口ファイルは、参照元を確認せず移動・改名・削除しない。
  • 資料室のMarkdown・HTMLのリンク先を定期的に照合する。
  • 構成整理を理由に本番DB・localStorage・GitHub Actionsを変更しない。
