📘 カクヨム連携ガイド

作品登録・しおり保存・目次取得・本棚での読了話数表示をまとめた資料室。

現行構成｜v3.6.1【2026/11/01】

カクヨム作品の登録としおりURLの保存に対応。作品別目次JSONを取得し、エピソードIDを話数へ変換して本棚カードに表示する。目次取得Actionは「カクヨム目次取得」。

1. 全体のしくみ

  1. カクヨム作品ページから作品情報を取得し、登録画面で確認する。
  2. 作品データを端末内に保存し、ともたよむの本棚に表示する。
  3. 読書中のエピソードを共有シートから既存ショートカット「とよむ➕しおり」へ渡す。
  4. ショートカットがカクヨムURLをともたよむへ渡し、作品カードのしおりURL・エピソードIDを更新する。
  5. GitHub Actions「カクヨム目次取得」で作品目次を取得し、作品IDごとのJSONとして保存する。
  6. 本棚が目次JSONとしおりのエピソードIDを照合し、読了話数を表示する。

2. 作品登録

kakuyomu_add.html は、作品情報テキストと作品URLを受け取り、解析結果を確認・修正して本棚へ登録する画面。

  1. 登録用ショートカットから作品情報テキストを受け取る（現状はクリップボード経由の貼り付け）。
  2. カクヨム作品ページのURLを入力する。
  3. 作品ID、タイトル、作者名、作者ハンドル、あらすじ、タグ、作品状態、総話数、文字数、最終更新日を確認・修正する。
  4. 登録先の本棚を選択し、本棚へ登録する。

作品データはlocalStorageの tomotaYomu_kakuyomu_works_v1 に保存される。登録先の棚情報はIndexedDB tomotaYomuDB から読み込む。

3. しおりの保存・再開

既存のiOSショートカット「とよむ➕しおり」にカクヨムURLの分岐を統合している。カクヨム公式アプリではなくBraveのWeb版を利用する運用。

  1. カクヨムのエピソードページを共有シートからショートカットへ渡す。
  2. ショートカットがURLを取り出し、URLエンコードしてともたよむを開く。
https://tomotaday.github.io/tomotayomu/index.html?kakuyomuUrl=エンコード済みURL

ともたよむはURLから作品IDとエピソードIDを解析し、登録済み作品の bookmarkEpisodeUrl と bookmarkEpisodeId を保存する。「続き📖」リンクはこの保存済みURLを開く。旧形式の kakuyomuId と episodeId による受け取りも互換性のため残している。

4. 作品目次の取得（GitHub Actions）

エピソードIDだけでは何話目か分からないため、作品ごとの目次をGitHub Actionsで取得する。

  1. 本棚の「⚙️管理設定用」から「カクヨム目次取得」を開く。
  2. GitHub Actionsで「Run workflow」を押す。
  3. 作品URL欄に対象作品のURLをそのまま貼り付ける。数字だけの作品ID入力にも対応。
  4. もう一度「Run workflow」を押して実行する。
  5. 成功すると data/kakuyomu-toc/作品ID.json としてGitHubリポジトリに保存される。

GitHub Actions：カクヨム目次取得を開く

取得時の検証

  • カクヨムが公表する総話数と抽出したエピソード数を照合する。
  • 検証用作品 1177354054891965415 に限り、先頭10話のIDと順序も既知の値と照合する。
  • 検証に不一致がある場合はActionを失敗として止め、リポジトリへ不完全なJSONを保存しない。

目次は作品ごとに取得する。別作品を取得するときは、初期入力の検証用URLを対象作品のURLに置き換える。

5. 本棚カードと読了話数

本棚カードは、保存済みしおりのエピソードIDを作品別目次JSONと照合し、話数を自動算出する。

続き📖345/1,132話
  • 照合成功：目次上の話数／総話数を表示。
  • 目次取得に失敗：目次未取得と表示。
  • 目次は取得できたがIDが見つからない：話数未照合と表示。
  • 「続き📖」を押すと、話数表示とは独立して保存済みエピソードURLを開く。

内容編集画面から「しおり（読了話数）」の手入力欄は廃止。しおりURLを正とし、読了話数は目次から自動算出する。総話数などの作品情報は引き続き編集できる。

6. 保存データと注意点

  • カクヨム作品情報・しおり：端末内localStorage tomotaYomu_kakuyomu_works_v1
  • 作品別目次：GitHubリポジトリ data/kakuyomu-toc/作品ID.json
  • 目次JSONは作品ごとに独立している。別作品のJSONで上書きされない。
  • 本棚カードの話数表示には、対象作品の目次JSONが必要。

このガイドは実装内容を整理したもの。Actionの成功や各作品での話数表示は、対象作品ごとの実行・実機確認をもって確認する。
